# Personal Learning Tracker v1.1.0

This release fixes a few bugs and adds a launcher icon to complete the One UI liquid glass experience!

### What's New
* **App Icon:** Added a shiny new vector app icon.
* **Topic Navigation Fix:** Clicking on a created topic now properly navigates into the Projects view filtered by that topic.
* **FAB Visibility Fix:** Fixed an issue in the Project Details screen where the floating action button (to add tasks/resources/notes) was hidden behind system navigation or bottom padding on certain devices.

### Installation
1. Download `LearningTracker.apk` from the assets below.
2. Transfer it to your Android device (if not downloading directly).
3. Open the APK file to install it (you may need to grant permission to "Install unknown apps").
